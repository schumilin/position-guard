它在做什么

仓位哨兵一直盯着你 OKX 账户里所有的永续合约仓位。每一条规则都在问同一个问题：

「现在的标记价，跟 N 分钟前那一刻的标记价 比，涨跌了多少？」达到你设的百分比，就执行这条规则的动作。

怎么算的：程序每秒把最新标记价记一个点。比如现在 12:05:20、规则是 3 分钟，那「3 分钟前那一刻」就是 12:02:20，基准价取记录里 12:02:20 那个点（那一秒正好缺了就取 12:02:21 的）。涨跌幅 =（现价 − 基准价）÷ 基准价。窗口随时间一直往前滚动，开仓前的走势也算在内，和杠杆倍数无关。

方向：「不利」= 多单遇跌、空单遇涨；「有利」= 多单遇涨、空单遇跌。

动作：市价全平 / 按比例平仓（比如平 50%）/ 只报警（弹窗 + 响铃，不动仓位）。

几个细节

  • 同一条规则触发后，对这个币同方向的仓位冷却 N 分钟（N 就是这条规则的窗口长度），避免刚平一半马上又把剩下的平掉。冷却期间其他规则照常工作。
  • 多条规则同时达到时，只执行最重的那个：全平 > 按比例平 > 只报警。
  • 按比例平仓时，按合约最小下单张数向下取整；凑不出合法张数或者剩下的太少，就改为全平。
  • 某个币超过 30 秒没收到标记价，就暂停对它的判断并报警，不会拿旧价格乱平。
  • 程序刚启动时，会用过去的 1 分钟 K 线收盘价把窗口补满，所以重启后保护马上生效。
怎么在 OKX 创建 API Key

先建模拟盘 Key 试用（用的是假钱）：

  1. 电脑浏览器打开 www.okx.com 登录，顶部「交易」→「模拟交易」进入模拟盘。
  2. 模拟盘里点「个人中心」→「模拟交易 API」→「创建」。
  3. 权限只勾「读取」和「交易」，不要勾「提现」；IP 地址留空；Passphrase 自己设一串并记住。
  4. 创建后会显示 API Key、Secret Key。Secret Key 只显示这一次，马上复制到本程序「设置」里保存。

试用满意后再建实盘 Key：实盘页面右上角头像 →「API」→「创建 API Key」，其余同上。然后在「设置」里切到「实盘」，填实盘 Key。

为什么 IP 留空：你是通过代理上网的，OKX 看到的 IP 是代理节点的，换节点就变。
代价：OKX 规定，没绑 IP、带交易权限的 Key 连续 14 天没被使用会被自动删除。本程序开着就一直在用，不会被删；如果程序关了超过 14 天，就需要重建一把。
为什么不能勾提现：本程序只需要平仓。万一 Key 泄露，没有提现权限，钱就转不走。勾了提现的 Key，本程序会直接拒绝使用。
菜单栏图标是什么意思

屏幕右上角菜单栏的「哨兵」图标：

  • 🟢 正常监控中
  • 🟡 已暂停：只看不动，不会自动平仓
  • 🔴 出问题了：断线、行情中断、Key 失效。点图标 →「打开控制面板」看原因
  • ⚪ 还没填 API Key
  • ⏳ 正在连接

点图标还可以：打开控制面板、暂停 / 恢复自动平仓、停止响铃、退出。

遇到报警怎么办
  • 「自动平仓失败」：程序已自动重试 3 次都没成功。立刻打开 OKX 手动处理这个仓位。
  • 「与 OKX 的连接中断」：先看代理软件开着没有、节点能不能用。断线期间不会自动平仓。连上后会自动恢复。
  • 「行情中断」：某个币一直收不到价格，一般跟断线是同一个原因。
  • 「仓位哨兵已停止工作」：API Key 失效或被删除了。去「设置」重新填一把 Key。
  • 怀疑程序乱平仓：马上点「暂停自动平仓」（页面右上角，或者菜单栏图标里），然后去「记录」看它为什么触发。
  • 怀疑 Key 泄露：在 OKX 的 API 管理里把这把 Key 删掉，删掉后立刻失效。

报警会弹窗并循环响铃，点弹窗的「知道了」或页面上的「停止响铃」就会停下。

它做不到的事（重要）
  • 电脑关机、断电、睡眠、退出登录、代理断开、OKX 接口故障时，它不工作。
  • 市价平仓会有滑点：行情剧烈时，实际成交价可能比触发时差不少。
  • 它看的是标记价格，和盘口最新成交价会有细微差别。
所以每个仓位仍然要在 OKX 上挂原生止损（持仓上的「止盈止损」）。原生止损挂在交易所的服务器上，电脑关机也照样有效；本程序是第二道防线。监控页会标出哪些仓位没挂原生止损。
这台电脑需要保持什么状态
  • 插着电源。程序运行时会自己阻止电脑睡眠；屏幕可以关、可以锁屏。
  • 不要退出登录账户，也不要合上笔记本盖子（合盖会强制睡眠）。
  • 代理软件开着，并且设成开机自启；打开「系统代理」，或者用 TUN / 增强模式。
  • 建议关掉 macOS 自动安装更新（系统设置 → 通用 → 软件更新），免得半夜重启。
  • 本程序默认开机自动运行（「设置」里可以关）。万一停电重启，要有人登录一次，程序才会运行。
