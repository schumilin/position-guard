它在做什么

仓位哨兵只盯你在「盯盘设置」里添加的标的，没添加的仓位一概不管。每个标的有两层条件，同时满足才会动手：

  1. 价格条件：标记价高于（或低于）你设的某个价格。只在触发那一刻看现价，价格回到另一边，规则就暂时不生效。
  2. 涨跌规则：现在的标记价，跟 N 分钟前那一刻的标记价比，涨（或跌）了 X% 以上。

两层都满足，就执行这条规则的动作：全平 / 按比例平仓 / 只报警。平仓会平掉这个标的上的所有仓位（多单空单都平）。

「N 分钟前那一刻」怎么取：程序每秒把最新标记价记一个点。比如现在 12:05:20、规则是 3 分钟，那一刻就是 12:02:20，取记录里 12:02:20 那个点（那一秒正好缺了就取 12:02:21）。窗口随时间一直往前滚，开仓前的走势也算在内，和杠杆无关。

怎么平：先下追逐委托（挂在买一 / 卖一价，每秒跟着价格调整）。如果在设定秒数内没有全部成交，或者价格跑得太远被 OKX 撤单，就撤掉追逐单，把剩下的部分改用市价平掉。秒数和最大追逐距离在「设置」里改。

几个细节

  • 同一条规则触发后冷却 N 分钟（N 就是它的窗口长度），避免刚平一半又马上把剩下的平掉。其他规则照常工作。
  • 多条规则同时达到，只执行最重的那个：全平 > 按比例平 > 只报警。
  • 按比例平仓按合约最小下单张数向下取整；凑不出合法张数或剩下太少，就改为全平。
  • 标的没有持仓时，平仓规则不会做任何事；「只报警」规则照样会响，可以当价格提醒用。
  • 某个标的超过 30 秒没收到标记价，就暂停对它的判断并报警，不会拿旧价格乱平。
  • 程序刚启动或刚添加标的时，会用过去的 1 分钟 K 线收盘价补满窗口，保护马上生效。
怎么在 OKX 创建 API Key
  1. OKX 网页或电脑客户端：右上角头像 →「API」→「创建 API Key」。
  2. 备注名随便写；账户选你平时开合约的那个；用途选「API 交易」。
  3. 权限：「读取」默认已勾，再只勾「交易」。提现、赚币、借贷、划转都不要勾。
  4. IP 白名单保持关闭；设一个密码（Passphrase）并记住。
  5. 点「提交全部」，输入验证码。页面会显示 API Key 和 Secret Key，Secret Key 只显示一次，马上复制到本程序。
为什么 IP 留空：你是通过代理上网的，OKX 看到的 IP 是代理节点的，换节点就变。
代价：没绑 IP、带交易权限的 Key 连续 14 天没被使用会被 OKX 自动删除。本程序开着就一直在用，不会被删；程序关了超过 14 天，就需要重建一把。
为什么不能勾提现：本程序只需要平仓。万一 Key 泄露，没有提现权限，钱就转不走。勾了提现的 Key，本程序会拒绝使用。
菜单栏图标是什么意思
  • 🟢 正常监控中
  • 🟡 已暂停：只看不动，不会自动平仓
  • 🔴 出问题了：断线、行情中断、Key 失效。点图标 →「打开控制面板」看原因
  • ⚪ 还没填 API Key
  • ⏳ 正在连接
遇到报警怎么办
  • 「自动平仓失败」：追逐委托和市价兜底都没成功。立刻打开 OKX 手动处理。
  • 「与 OKX 的连接中断」：先看代理软件开着没有、节点能不能用。断线期间不会自动平仓。
  • 「行情中断」：某个标的一直收不到价格，一般跟断线是同一个原因。
  • 「仓位哨兵已停止工作」：API Key 失效或被删除了，去「设置」重新填。
  • 怀疑程序乱平仓：马上点「暂停自动平仓」，然后去「记录」看它为什么触发。
  • 怀疑 Key 泄露：在 OKX 的 API 管理里删掉这把 Key，立刻失效。
它做不到的事（重要）
  • 电脑关机、断电、睡眠、退出登录、代理断开、OKX 接口故障时，它不工作。
  • 追逐委托在急涨急跌时可能追不上，这时会改市价兜底；市价单行情剧烈时会有明显滑点。
  • 它看的是标记价格，和盘口最新成交价会有细微差别。
每个仓位仍然要在 OKX 上挂原生止损（持仓上的「止盈止损」）。原生止损挂在交易所服务器上，电脑关机也有效；本程序是第二道防线。
这台电脑需要保持什么状态
  • 插着电源。程序运行时会自己阻止睡眠；屏幕可以关、可以锁屏。
  • 不要退出登录，也不要合上笔记本盖子（合盖会强制睡眠）。
  • 代理软件开着并设成开机自启，打开「系统代理」，或用 TUN / 增强模式。
  • 建议关掉 macOS 自动安装更新（系统设置 → 通用 → 软件更新），免得半夜重启。
  • 本程序默认开机自动运行。停电重启后要有人登录一次，程序才会运行。
