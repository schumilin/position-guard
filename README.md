# 仓位哨兵 PositionGuard

OKX 永续合约「价格条件 + N 分钟涨跌幅」自动平仓的 macOS 菜单栏应用。完整的需求和产品逻辑见 [docs/产品文档.md](docs/产品文档.md)。

- 只盯用户添加的标的；每个标的先设价格条件（标记价高于 / 低于某价，必填），条件当下满足时，规则「和 N 分钟前比涨 / 跌 X%」才生效。
- 触发后平掉这个标的上的所有仓位：先下追逐委托，超时或被撤单就把剩余部分改市价兜底。
- 安全：代码里只有平仓、没有开仓；带提现权限的 API Key 拒绝使用；Key 存 macOS 钥匙串；控制面板只监听 127.0.0.1 并校验令牌。

## 开发

```bash
uv sync
uv run pytest -q
uv run python -m guard.app --headless   # 不带菜单栏，终端里打印控制面板地址
```

## 打包

```bash
./scripts/build.sh   # 产出 dist/PositionGuard.app 和 dist/PositionGuard.zip（Apple 芯片，macOS 11+）
```

应用未经 Apple 签名公证，拷到别的 Mac 后需执行 `xattr -cr /Applications/PositionGuard.app` 才能打开。

## 安装 / 更新

1. 如果旧版本还开着：点菜单栏「哨兵」→「退出仓位哨兵」。
2. 把 `dist/PositionGuard.zip` 用 AirDrop 或 U 盘拷到目标 Mac，解压后拖进「应用程序」（覆盖旧版本时选「替换」）。
3. 在终端里执行下面这行，否则 macOS 会提示「已损坏」：
   ```bash
   xattr -cr /Applications/PositionGuard.app && open /Applications/PositionGuard.app
   ```
4. 更新版本后，如果弹出钥匙串授权，输入开机密码，选「始终允许」。之前保存的 API Key 会保留。
5. 首次使用时，在控制面板里按引导填写 OKX API Key：只勾「读取」和「交易」，IP 白名单保持关闭。

## 实盘实测要点

用小仓位实测，按顺序做。每一步都可以在控制面板的「记录」页核对程序做了什么。

1. **报警链路**：在「盯盘设置」里添加测试标的。价格条件设成现在一定满足的，比如「低于」一个远高于现价的价格。再加两条规则：「1 分钟 · 跌 · 0.01% · 只报警」和「1 分钟 · 涨 · 0.01% · 只报警」。一两分钟内应该会弹窗并响铃，点「知道了」。这一步只验证行情、锚点计算和报警，不动仓位。
2. **追逐委托按比例平仓**：把其中一条规则的动作改成「按比例平仓 50%」。触发后：
   - OKX 的委托列表里应该出现一笔追逐委托；
   - 仓位剩一半；
   - 「记录」里写的是「**追逐委托已成交**」，或者是「**追逐委托下单失败（原因），已改市价平掉剩余**」。如果是后者，说明 OKX 不接受当前的追逐参数，平仓仍然靠市价完成了，把这条记录的原因发给开发协助者修。
3. **全平**：把这条规则改成「全平」。同一条规则触发后会冷却 N 分钟（这里是 1 分钟），等冷却结束，剩下的仓位应该被平掉。
4. **价格条件**：把价格条件改成现在不满足的那一侧，比如「低于」一个远低于现价的价格。监控页的规则会显示「价格条件不满足」，即使涨跌幅达到了也不会触发。
5. **追逐超时兜底**（可选）：在「设置 → 平仓方式」里把超时调到 3 秒，在盘口较薄的标的上触发一次平仓。「记录」里应该能看到「追逐委托 3 秒内没有全部成交……已改市价平掉剩余」。测完把超时改回去。
6. **断线报警**：在代理软件里关掉系统代理，30 秒内应该弹窗报警，菜单栏图标变红。打开代理后会自动恢复。
7. **收尾**：删掉测试规则，设好正式的价格条件和规则；给每个仓位在 OKX 上挂好原生止损；确认菜单栏图标是 🟢。

出问题时：在「设置」页最下面点「打开日志文件夹」，把 `app.log` 发给开发协助者（日志里没有 Key）。

## 目录

- `guard/engine.py` 监控引擎：采样、价格条件与规则判断、追逐委托平仓与市价兜底、健康检查
- `guard/rules.py` / `guard/series.py` 规则计算与价格序列（纯函数）
- `guard/okx.py` OKX REST / WebSocket 客户端
- `guard/web.py` + `guard/static/index.html` 本机控制面板
- `guard/app.py` 入口与菜单栏
- 运行数据：`~/Library/Application Support/PositionGuard/`（配置、事件记录、日志）
